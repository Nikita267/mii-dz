# Тестовый проект ДЗ1 — компонент «Трекер привычек»

Создан с помощью AI-агента (Claude Code) для проверки работы выбранного инструмента (Шаги 4–5 ДЗ1). Первые заготовки для сквозного проекта курса.

## Состав

- `streak.js` — функция `calculateStreak(entries, today)`: длина текущей серии выполнений привычки по списку дат 'YYYY-MM-DD'. Работает в Node.js и браузере.
- `streak.test.js` — 6 юнит-тестов (node:test), включая краевые случаи: пустой список, перерыв, граница месяца, «мёртвая» серия.
- `index.html` — компонент HabitCard на vanilla JS + CSS: три привычки на Mock-данных, клик по чекбоксу отмечает выполнение и пересчитывает серию.

## Запуск

Тесты:
```
node --test
```
Ожидаемый результат: `pass 6, fail 0`.

Демо компонента: открыть `index.html` в браузере.

## История итераций

- v1: серия считалась сравнением номеров дней (`getDate()`) — тест «переход месяца» упал (2 ≠ 4).
- v2: сравнение полных дат в мс — все 6 тестов зелёные.
