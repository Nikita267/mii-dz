# ДЗ1 · Сравнительная таблица AI-инструментов разработки

Задача: веб-приложение «Трекер привычек» (локальный git-репозиторий, VS Code, стек React/Vite/Tailwind + Supabase + Vercel; требования зафиксированы в `требования.md`).
Данные собраны 08.10.2026 из официальных страниц цен/документации и независимых обзоров (12 research-агентов + перекрёстная перепроверка; источники в конце файла).

## 4. Обоснование оценок по критериям

### Доступ к контексту проекта
- **Bolt.new (3)** — браузерная среда (WebContainer), весь проект виден чату, есть .boltignore и file locking, двусторонняя синхронизация с GitHub; но индексации кодовой базы нет, в длинных чатах ранний контекст «забывается», локальная ФС недоступна.
- **Lovable (2)** — код живёт в облаке Lovable; импорт существующего репозитория официально не поддерживается (git-sync только на экспорт) — для работы в существующем репо это блокер.
- **Replit Agent (3)** — облачный workspace, агент видит весь проект, постоянная память replit.md; локальных IDE/CLI нет.
- **Cursor (5)** — локальный репозиторий, семантическая индексация кодовой базы (эмбеддинги в векторной БД, пути шифруются), мгновенный grep-поиск, @-контексты, git-worktrees для параллельных агентов.
- **GitHub Copilot (4)** — плагин в VS Code видит локальные файлы и git; агентный режим правит несколько файлов; семантическая индексация ориентирована на GitHub-репозитории (для остальных выключена по умолчанию).
- **Claude Code (5)** — агент работает поверх локального проекта: сам читает/ищет/правит файлы, выполняет команды в терминале, git/gh из коробки, постоянная память CLAUDE.md, контекстное окно до 1M токенов с авто-компакцией.

### Скорость генерации кода
- **Bolt.new (5)** — самый быстрый прототип: ~30 сек на отклик (вдвое быстрее Lovable) и ~28 минут от нуля до работающего приложения без настройки окружения.
- **Lovable (4)** / **Replit Agent (4)** — full-stack прототип за минуты; Replit Agent 4 с параллельными агентами; Turbo-режим ×2.5 скорости (но до ×6 дороже).
- **Cursor (4)** — одно из самых быстрых инлайн-дополнений Tab; быстрая и дешёвая собственная модель Composer.
- **GitHub Copilot (4)** — мгновенные completions; по официальному исследованию GitHub агентный harness экономичнее вендорских по токенам.
- **Claude Code (4)** — глубокие агентные сессии не мгновенны (это плата за качество); fast mode ускоряет генерацию до ×2.5.

### Качество кода
- **Bolt.new (2)** — код ровный, но шаблонный (сильная опора на shadcn/ui), результат — прототип, требующий доработки; в формальных бенчмарках не участвует.
- **Lovable (3)** — структура кода лучше, чем у Bolt (обзоры), но деградация на больших проектах, склонность переписывать файлы целиком; известный кейс утёкшего в клиентский код ключа Supabase.
- **Replit Agent (3)** — сильная автономность и самотестирование в браузере с автофиксами; единственная точка данных HumanEval+ ~88.9% против 94.1% у Cursor+Sonnet.
- **Cursor (4)** — высокие результаты CursorBench 4.0 (Grok 4.7: 46.3%) и Terminal-Bench (38%); слабое место — масштабные многофайловые рефакторинги.
- **GitHub Copilot (4)** — агентный harness на уровне вендорских (SWE-bench Verified/Pro) при меньшем расходе токенов; лидер Gartner MQ for AI Code Assistants 2 года подряд.
- **Claude Code (5)** — модели Claude — лидеры публичных бенчмарков: Opus 5 — 97% SWE-bench Verified (№1 независимого лидерборда vals.ai, окт. 2026), Opus 5.5 — 89.9% SWE-bench Pro (№1); сильные многофайловые правки и длинные горизонты задач.

### Стоимость использования
- **Bolt.new (4)** — щедрый Free: 300K токенов/день, 1M/мес, без карты (токены тратятся и на чтение файлов/промптов — на крупном проекте квота тает); Pro $25/мес.
- **Lovable (2)** — Free: всего 5 билд-кредитов/день (≤30/мес), ручная правка кода недоступна на Free; Pro $25/мес, по обзорам реальные чеки выше из-за докупок.
- **Replit Agent (3)** — Starter $0 с дневными лимитами; Core $20/мес ($18 годовой); effort-based биллинг — по обзорам реальные расходы заметно выше подписки.
- **Cursor (3)** — Hobby $0 без карты (лимиты официально не публикуются); Pro $20/мес + usage-based доплаты; бесплатный студенческий год отменён с 25.06.2026.
- **GitHub Copilot (5)** — лучший бесплатный вариант: Free (2000 completions/мес + кредиты), отдельный бесплатный план **Student** для верифицированных студентов (безлимитные completions); Pro всего $10/мес.
- **Claude Code (2)** — бесплатного тарифа нет (в сравнении тарифов для Free — «No»), Pro $20/мес, индивидуальной студенческой скидки нет. **В нашем случае уже есть действующий доступ — предельная стоимость для проекта равна нулю.**

### Безопасность данных
- **Bolt.new (3)** — обучение на данных пользователей по умолчанию (opt-out есть; Forge — строго opt-in); код исполняется локально в браузерной песочнице; сторонние оценки — средний риск.
- **Lovable (3)** — обучение по умолчанию, но с сентября 2026 self-service opt-out на любом тарифе; SOC 2 Type II, ISO 27001; код хранится в облаке платформы.
- **Replit Agent (2)** — политика допускает использование данных для улучшения ML; пользовательского переключателя «не обучать» не найдено; весь код в облаке.
- **Cursor (4)** — Privacy Mode (zero data retention) включается вручную; индексация — эмбеддинги в удалённой векторной БД (пути шифруются); для Teams/Enterprise режим принудителен.
- **GitHub Copilot (3)** — с 24.04.2026 на индивидуальных планах обучение включено по умолчанию (opt-out в настройках); Business/Enterprise защищены DPA; индексация для обучения не используется.
- **Claude Code (4)** — команды и файлы исполняются локально, машину не покидают; в API уходят промпты/фрагменты; на потребительских тарифах обучение по умолчанию с 28.09.2025 (opt-out в настройках), на Team/API — только с явного согласия.

### Удобство интеграции в рабочий процесс
- **Bolt.new (3)** — только браузер; синхронизация с GitHub по запросу; MCP поддерживается; экспорт zip — для нашего VS Code-процесса лишний шаг пересылки.
- **Lovable (2)** — браузер + десктоп-приложения (macOS/Windows); VS Code-расширения нет; существующий репозиторий не импортируется.
- **Replit Agent (3)** — собственная облачная IDE со встроенными БД и деплоем; GitHub push/pull; локальной интеграции нет.
- **Cursor (4)** — форк VS Code (расширения совместимы, миграция лёгкая), но это смена редактора; CLI только macOS/Linux (для Windows минус); MCP полный.
- **GitHub Copilot (5)** — плагин прямо в наш VS Code, смена окружения нулевая; CLI, десктоп-приложение, нативная интеграция с GitHub; MCP.
- **Claude Code (5)** — CLI + официальное расширение VS Code (уже установлено и работает), git/gh нативно, GitHub Actions, MCP (в проекте настроены 3 сервера), hooks/skills/субагенты.

## 5. Выбор инструмента и обоснование (Шаг 3)

**Выбран: Claude Code** (взвешенная оценка 43/50).

Ключевые факторы решения (в порядке влияния):
1. **Полное соответствие главному требованию** — работа с локальным git-репозиторием: агент сам читает и правит файлы проекта, выполняет команды (npm, тесты, git), чего Cloud-агенты принципиально не делают.
2. **Качество агентной разработки** — лучший результат публичных бенчмарков (SWE-bench Verified 97%, SWE-bench Pro 89.9% — №1): важно, поскольку проект сквозной (ДЗ4–6 — реальное приложение с тестами, бэкендом и CI/CD), а не одноразовый прототип.
3. **Нулевая стоимость внедрения** — инструмент уже развёрнут в рабочем окружении (CLI 2.1.205 + расширение VS Code + настроенные MCP-серверы), ничего устанавливать не нужно; формальная слабость «нет бесплатного тарифа» в нашем случае не действует.
4. **Приемлемая безопасность** — код исполняется локально; обучение на данных на потребительском тарифе отключается в настройках (отметить при сессиях с чувствительными данными).

**Альтернативы и почему не подошли:**
- **GitHub Copilot (42)** — ближайший конкурент и лучший вариант при нулевом бюджете: бесплатен для верифицированных студентов, интеграция в VS Code идеальна. Не выбран основным, потому что на Free/Student доступны только авто-подбор модели и жёсткие лимиты агентных кредитов (агентная работа над целым приложением их быстро исчерпает), а качество агентных многофайловых сессий уступает Claude. **Рекомендация: держать как второй инструмент** (бесплатные инлайн-подсказки в том же VS Code).
- **Cursor (40.5)** — сильнейший IDE-конкурент с собственной индексацией кодовой базы. Не выбран: требует перехода на другой редактор (форк VS Code), полноценная работа — от $20/мес, студенческий бесплатный год отменён.
- **Bolt.new (31.5)** — лучший по скорости прототипирования «с нуля» (~28 минут до работающего приложения) и щедрому Free. Не подошёл как основной: браузерная среда без доступа к локальным файлам, код шаблонного прототипного качества, контекст «забывается» в длинных чатах. Ниша применения в нашем курсе — быстрые одноразовые прототипы.
- **Replit Agent (29.5)** — сильная автономность (параллельные агенты, самотестирование), всё в одном облаке (БД + деплой). Не подошёл: код и данные в чужом облаке, effort-based биллинг с непредсказуемыми чеками, политика данных без пользовательского opt-out.
- **Lovable (25.5)** — минимальные требования к пользователю, качественный UI-код. Не подошёл решающе: импорт существующего репозитория не поддерживается — противоречит базовому требованию проекта.
