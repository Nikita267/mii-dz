# Bolt.new  [Cloud]
## models
- Под капотом — коммерческие LLM сторонних провайдеров, свою модель Bolt не имеет. Основа — модели Anthropic Claude: по официальному блогу Bolt (декабрь 2025, «New in Bolt: Use Claude Opus & Haiku») пользователь может переключаться между Claude Haiku, Sonnet и Opus прямо в сайдбаре агента; по обзорам 2026 г. дефолт — Claude Sonnet.
- Выбор модели возможен: переключатель в интерфейсе чата/агента; премиум-модели (Claude Opus и др.) расходуют больше токенов из месячной квоты («Opus uses more tokens for better reasoning»). Полный доступ к выбору моделей может зависеть от тарифа.
- Обзоры и новости также упоминают в меню модели OpenAI GPT, Google Gemini и открытые модели (в Bolt Forge, сентябрь 2026, — DeepSeek v4 Pro как экспериментальная опция), но официальный актуальный список моделей на дату 08.10.2026 в открытом виде не публикуется.
- Self-hosted-версия bolt.diy (open source, GitHub stackblitz-labs/bolt.diy, 55k+ звёзд) позволяет подключить любой LLM по своему API-ключу: OpenAI, Anthropic, Google, Mistral, xAI, DeepSeek, Ollama (локальные модели) и др.
- Точная привязка конкретных моделей к тарифам и точный мультипликатор расхода токенов премиум-моделями — не удалось подтвердить официально (см. uncertainty).
## pricing.free: Free ($0/мес): публичные и приватные проекты; 300 000 токенов/день и 1 000 000 токенов/мес; хостинг сайтов с брендингом Bolt; лимит загрузки файлов 10 МБ; до 333K веб-запросов; неограниченное число БД. Регистрация без карты. Неиспользованные токены на Free не переносятся на следующий месяц.
## pricing.paid:
- Pro — $25/мес (при годовой оплате дешевле, до -28%): без дневного лимита; от 10M токенов/мес; без брендинга Bolt; приватный доступ к сайтам (share privately); загрузка файлов до 100 МБ; до 1M веб-запросов; перенос неиспользованных токенов (rollover); свой домен; выбор провайдера БД; AI-редактирование изображений
- Teams — $30/участник/мес (годовая — со скидкой): всё из Pro + централизованный биллинг, управление доступами на уровне команды, приватные NPM-реестры, «знание дизайн-системы» с подсказками по пакетам
- Enterprise — цена по договору (custom): SSO/SAML, аудит-логи, поддержка комплаенса, выделенный аккаунт-менеджер и поддержка 24/7, SLA, data governance и политики хранения данных
- Дозакупка токенов: $20 за 10M токенов — доступна только на самом высоком тарифе или годовой подписке (nocode.mba, 2026)
## pricing.notes: Скрытые ограничения: (1) токены расходуются не только на генерацию кода, но и на чтение промптов, файлов проекта и «размышления» модели — на крупном проекте квата тает быстро (обзор May 2026, banani.co: реальные затраты превышают цену тарифа); (2) у Free жёсткий дневной лимит 300K; (3) премиум-модели (Opus) расходуют больше токенов; (4) докупка токенов доступна не всем (только высший тариф или годовая подписка); (5) на годовой подписке скидка до 28%.

# Lovable  [Cloud]
## models
- Мультимодельная архитектура; пользователь НЕ может выбрать модель — по документации Lovable автоматически подбирает модель под тип задачи/«тир» и обновляет выбор при выходе новых моделей.
- Anthropic Claude — основные модели для генерации кода; в июне 2026 Lovable и Google Cloud объявили расширенное многолетнее партнёрство, включающее расширенный доступ к моделям Claude (через Google Cloud) вместе с Gemini.
- Google Gemini — использовался как модель по умолчанию для встроенных AI-функций приложений (Lovable AI) при запуске в сентябре 2025.
- OpenAI — модели для генерации изображений (например, «Fast»-тир изображений использует GPT Image 2.5 Flare по документации).
- Историческая справка: проект вырос из open-source GPT Engineer; инженерные разборы (ZenML) описывали гибрид: OpenAI GPT-4 Mini для быстрых задач + Claude 3.5 Sonnet для сложной генерации кода. Точный текущий состав моделей компанией не раскрывается.

- Pro — $20/мес (или $17/мес при годовой оплате, $200 сразу): включает Claude Code (терминал), модели Sonnet/Haiku/Opus (+ Fable за usage credits)
- Max 5x — $100/мес: в 5 раз больше лимитов сессий Pro, все модели (Fable — 50% недельного лимита), ранний доступ к функциям
- Max 20x — $200/мес: в 20 раз больше лимитов Pro
- Team — Standard ~$25/место/мес ($20 при годовой), Premium seat ~$125/мес ($100 годовой): Claude Code включён, нет обучения на данных по умолчанию
- Enterprise (self-serve) — $20/место/мес при годовой оплате + потребление по API-ставкам; custom-контракт с продажами
- API/Console — pay-as-you-go за токены: Fable 5.1 $10/$50, Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Haiku 5.5 tiered за 1M input/output
## pricing.notes: Скрытые ограничения: лимиты не в токенах, а «пользованию» — скользящее 5-часовое окно сессий + недельные лимиты, общий пул на всех поверхностях (web/desktop/mobile/Claude Code); цифры официально не публикуются и меняются. При исчерпании лимита — докупка usage credits по стандартным API-ставкам. Fable на нижних тарифах урезан. Fast mode (Opus 5.5) — ускорение до ~2.5x за двойную цену токенов. Годовая оплата Pro экономит ~15%.
## context: Claude Code работает агентно поверх ЛОКАЛЬНОГО проекта: сам читает файлы (инструменты Read/Grep/Glob), правит их (Edit/Write), выполняет команды в терминаке (Bash) — то есть видит весь каталог/репозиторий по мере необходимости, а не один открытый файл и не статический индекс всего проекта. Полная работа с git-репозиторием из коробки (diff, commit, branch, PR через gh). Постоянная память проекта — файлы CLAUDE.md (создаются /init, автоматически загружаются в каждой сессии; иерархия: user ~/.claude/CLAUDE.md, проектный, подпапки) плюс авто-память; команда # добавляет факт в память. Контекстное окно зависит от модели: у актуальных моделей до 1 млн токенов (по документации model-config: Fable 5.1/5, Sonnet 5/5.5, Haiku 5.5, Opus начиная с 4.7 имеют 1M на любом тарифе; старые модели — 200K, для некоторых есть [1m]-варианты с требованиями к тарифу).
