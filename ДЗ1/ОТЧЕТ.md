## 1. Задача и требования (Шаг 1)

**Задача разработки:** веб-приложение «Трекер привычек» — SPA (список привычек, ежедневные отметки, серии, статистика). Задача выбрана как старт сквозного проекта курса: это же приложение развивается в ДЗ3 (ТЗ, UI-концепции) → ДЗ4 (Frontend) → ДЗ5 (Backend + БД) → ДЗ6 (CI/CD). Ориентировочный стек: React + Vite + Tailwind CSS, Supabase, деплой на Vercel.

**Профиль требований** (полностью — в `требования.md`):

| Требование | Значение для выбора инструмента |
|---|---|
| Сложность: средняя (типовое SPA, CRUD, авторизация) | нужны итеративные доработки, а не только генерация с нуля |
| Доступ к локальным файлам: **нужен** (git-репозиторий, npm, тесты) | Cloud-агенты проигрывают принципиально |
| Безопасность данных: умеренная (в ДЗ5 — авторизация и ключи) | важна политика обучения на коде и место исполнения кода |
| Бюджет: минимальный (студенческий) | решают бесплатные/уже оплаченные инструменты |
| Процесс: семестр, работа в VS Code + GitHub | интеграция в существующее окружение |

## 2. Сравнительный анализ инструментов (Шаг 2)

Сравнены 6 инструментов (минимум задания — 2 Cloud + 2 IDE/CLI, выполнено с запасом): **Bolt.new, Lovable, Replit Agent** (Cloud) и **Cursor, GitHub Copilot, Claude Code** (IDE/CLI). Каждый оценён по 6 критериям задания (баллы 1–5): доступ к контексту проекта, скорость генерации, качество кода, стоимость, безопасность данных, удобство интеграции.

Данные собраны research-агентами из официальных источников (страницы цен, документация, changelog) и независимых обзоров по состоянию на 08.10.2026, затем **независимо перепроверены** вторым набором агентов (найдены и исправлены устаревшие сведения — например: у Bolt теперь выбор агента вместо выбора модели; у Lovable появились десктоп-приложения и self-service opt-out; в Copilot нет моделей GPT-6; студенческий бесплатный год Cursor отменён с 25.06.2026; обучение на consumer-тарифах Anthropic действует с 28.09.2025).

## 3. Обоснование выбора (Шаг 3)

**Выбранный инструмент: Claude Code** (CLI + расширение VS Code).

Ключевые факторы:
1. **Доступ к контексту локального репозитория** — главное требование задачи: агент сам читает/правит файлы, запускает команды (npm, тесты, git), поддерживает git/gh нативно, память проекта CLAUDE.md, окно до 1M токенов.
2. **Качество кода** — модели-лидеры публичных бенчмарков (Opus 5: 97% SWE-bench Verified — №1 независимого лидерборда vals.ai, окт. 2026; Opus 5.5: 89.9% SWE-bench Pro). Для сквозного проекта ДЗ4–6 (реальное приложение с тестами и CI/CD) это важнее скорости прототипирования.
3. **Нулевая стоимость внедрения** — уже установлен и настроен в рабочем окружении (CLI 2.1.205, расширение VS Code, 3 MCP-сервера), формальный минус «нет бесплатного тарифа» на наш случай не действует — доступ уже есть.
4. **Безопасность** — команды и файлы исполняются локально; обучение на данных на потребительском тарифе отключается в настройках (принятый и контролируемый риск для учебного проекта).

**Альтернативы:**
- *GitHub Copilot* (2-е место) — лучший вариант при нулевом бюджете (бесплатен для верифицированных студентов); не выбран основным из-за жёстких лимитов агентных кредитов на Free/Student и отсутствия выбора моделей; **рекомендован как второй инструмент** (бесплатные инлайн-подсказки).
- *Cursor* (3-е место) — сильнейший IDE-конкурент; требует смены редактора и $20/мес.
- *Bolt.new / Replit Agent / Lovable* — отличные генераторы прототипов «с нуля», но противоречат базовым требованиям задачи (нет доступа к локальным файлам; Lovable не импортирует существующий репозиторий; код и данные в чужом облаке; тарификация кредитами/токенами с быстрым сгоранием).

## 5. Примеры работы с инструментом (Шаг 5)

Задача: функция расчёта серии привычки + компонент HabitCard на Mock-данных + юнит-тесты.
Процесс занял **2 итерации**:
- **Итерация 1:** агент сгенерировал `streak.js` (v1), `streak.test.js` (6 тестов) и `index.html`. Прогон `node --test`: 5/6, упал кейс перехода месяца (`2 !== 4`) — в v1 даты сравнивались по номеру дня в месяце.
- **Итерация 2:** исправление на сравнение полных дат в мс → **6/6 зелёные**.

Сложности: (а) логическая ошибка агента в v1 — поймана тестом на краевой случай, исправлена за одну итерацию; (б) объёмное веб-исследование инструментов заняло ~2 часа — вывод: такие задачи выгоднее дробить. Полный журнал с реальными промптами и выводами консоли: `демонстрация/журнал_сессии.md`.

## 6. Выводы и рекомендации

1. **Классы инструментов решают разные задачи.** Cloud-агенты (Bolt/Lovable/Replit) — быстрое прототипирование «с нуля» (~28 минут до работающего приложения у Bolt), IDE/CLI-агенты — итеративная работа в существующем репозитории. Для многоэтапного проекта с git-репозиторием, тестами и деплоем выбор IDE/CLI-агента закономерен.
2. **Балльная таблица без привязки к требованиям задачи вводит в заблуждение**: без весов лидируют Copilot и Claude Code одинаково; веса из профиля задачи (локальные файлы, интеграция, качество) дают осмысленное ранжирование.
3. **Данные инструментов быстро устаревают** (за 2026 год: отмена студенческого года Cursor, переход Copilot на usage-based биллинг, смена модели тарификации Lovable) — перед принятием решений платного уровня цены нужно перепроверять на официальных страницах.
4. **Для курса:** Copilot Student — полезный бесплатный «второй пилот» в том же VS Code; Cloud-агенты пригодятся в ДЗ3 для быстрого перебора UI-вариаций. Выбранный Claude Code закрывает всю оставшуюся цепочку (ДЗ2–ДЗ6) без смены окружения.
5. **Практический урок агентной работы:** ошибки агента (сравнение дат) дешевле всего ловятся тестами на краевые случаи, запрошенными у агента сразу — это напрямую пригодится в ДЗ4, где тесты — обязательный критерий.
