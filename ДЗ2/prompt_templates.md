# ДЗ2 · Шаг 3 — Библиотека промпт-шаблонов

6 шаблонов (минимум задания — 5) для типовых сценариев разработки. Каждый оформлен по структуре **RTCF** (Role-Task-Context-Format) в Markdown-блоках; к каждому — заполненный пример использования из проекта «Трекер привычек». Место заполнения отмечено как `<...>`.

---

## Шаблон 1. Генерация компонента/функции по описанию

```text
**Role:** Ты — Senior Frontend-разработчик в проекте «Трекер привычек»
(React + Vite + Tailwind CSS, утилиты — чистые функции с JSDoc).

**Task:** Разработай <компонент | функцию> по описанию:
<описание задачи и поведения>.

**Context:** Проект — SPA трекера привычек (привычки, ежедневные отметки,
серии, статистика). Структура: src/components/, src/hooks/, src/utils/.
Переиспользуй существующее: <утилиты/компоненты, которые уже есть>.
Правила проекта: CLAUDE.md (без новых зависимостей, без any, JSDoc на
экспортах, состояния loading/error/success).

**Format:** Полный код файла с путём; JSDoc/типы пропсов; краткое описание
решений (2–3 строки); как проверить (запуск/тест).
```

**Пример использования:**
> **Role:** Ты — Senior Frontend-разработчик в проекте «Трекер привычек»...
> **Task:** Разработай компонент `HabitCard`: карточка привычки с чекбоксом отметки на сегодня, счётчиком текущей серии (🔥 N) и серым состоянием для «оборванной» серии; клик по чекбоксу вызывает колбэк и блокируется на время сохранения.
> **Context:** ...Переиспользуй `calculateStreak(entries, today)` из `src/utils/streak.js`. Данные приходят пропсом `habit = { id, name, icon, entries[] }`.
> **Format:** Файл `src/components/HabitCard.jsx` + пример использования в комментарии.

## Шаблон 5. Декомпозиция сложной задачи на подзадачи

```text
**Role:** Ты — техлид проекта «Трекер привычек», планирующий работу
разработчика (или AI-агента).

**Task:** Декомпозируй задачу на подзадачи, пригодные для выполнения
за одну итерацию агента.

**Context:** Задача целиком: <описание>. Существующий код/инфраструктура:
<что уже есть>. Ограничения: стек и правила CLAUDE.md, срок <...>.

**Format:** Нумерованный список подзадач (3–7), для каждой: цель,
артефакты (файлы), критерий готовности, зависимости от других подзадач.
В конце — рекомендуемый порядок выполнения.
```

**Пример использования:**
> **Task:** Декомпозируй: «Экран статистики: графики выполнения за месяц и лучшая серия».
> **Context:** Существует `src/utils/stats.js` (серии, процент выполнения); графики без новых зависимостей (SVG/CSS).
> **Format:** ...подзадачи: (1) функция группировки отметок по дням месяца, (2) компонент `MonthChart`, (3) компонент `BestStreakBadge`, (4) экран `StatisticsScreen`...

**Пример использования:**
