# Методы искусственного интеллекта — домашние задания

Сквозной учебный проект курса: **веб-приложение «Трекер привычек»** (React + Vite + Tailwind CSS, Supabase, деплой Vercel), развиваемый от сравнительного анализа AI-инструментов до CI/CD.

Работы выполняются в паре с AI-агентом **Claude Code** (обоснование выбора инструмента — в ДЗ1).

## Структура репозитория

| Папка | Задание | Статус |
|---|---|---|
| `ДЗ1/` | Сравнительный анализ и настройка AI-инструментов (6 инструментов, выбор Claude Code) | ✅ готово |
| `ДЗ2/` | Система правил агента (CLAUDE.md), промпт-шаблоны RTCF, Chain-of-Thought, A/B-тест правил (94 теста) | ✅ готово |
| `ДЗ3/` | UI-концепции (3 шт.), пользовательские истории (19 шт. с Given-When-Then), техническое задание (70 FR + 18 NFR) | ✅ готово |
| `ДЗ4/` | Frontend-приложение по ТЗ из ДЗ3 | 🔜 в работе |

Каждая папка содержит полный комплект артефактов сдачи и собственный отчёт; входной точкой в каждом ДЗ служит `ОТЧЕТ.md` / файлы по формату сдачи задания.
