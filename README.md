# Методы искусственного интеллекта — домашние задания

Сквозной учебный проект курса: **веб-приложение «Трекер привычек»** (React + Vite + Tailwind CSS, Supabase, деплой Vercel), развиваемый от сравнительного анализа AI-инструментов до CI/CD.

Работы выполняются в паре с AI-агентом **Claude Code** (обоснование выбора инструмента — в ДЗ1).

## Продакшн

| Что | Где |
|---|---|
| Приложение | <https://mii-dz.vercel.app> |
| Health-check | <https://mii-dz.vercel.app/api/health> — `200 {"status":"ok"}` |
| Вход | email+пароль и OAuth2 Google (Supabase Auth) |
| Аналитика | Яндекс.Метрика, счётчик № 113599598 |
| Мониторинг | UptimeRobot: Keyword `"status":"ok"` на `/api/health`, раз в 5 минут |
| CI/CD | GitHub Actions: lint → 170 тестов → build → деплой Vercel при push в `main` |

Примечание: домен `*.vercel.app` в РФ блокируется нестабильно (блокировка
РКН «мигрирует» между подсетями) — при недоступности открыть через VPN.

## Структура репозитория

| Папка | Задание | Статус |
|---|---|---|
| `ДЗ1/` | Сравнительный анализ и настройка AI-инструментов (6 инструментов, выбор Claude Code) | ✅ готово |
| `ДЗ2/` | Система правил агента (CLAUDE.md), промпт-шаблоны RTCF, Chain-of-Thought, A/B-тест правил (94 теста) | ✅ готово |
| `ДЗ3/` | UI-концепции (3 шт.), пользовательские истории (19 шт. с Given-When-Then), техническое задание (70 FR + 18 NFR) | ✅ готово |
| `ДЗ4/` | Frontend-приложение по ТЗ из ДЗ3 | ✅ готово |
| `ДЗ4/habit-tracker/` | **Сквозное приложение ДЗ4→ДЗ6.** ДЗ5: бэкенд Supabase (миграции с RLS, Auth, фасад Mock↔облако), e2e 11/11 | ✅ ДЗ5 готово |
| `ДЗ6/` | CI/CD (GitHub Actions + Vercel), аудит безопасности, OAuth2 Google, аналитика Метрика, health-check, мониторинг UptimeRobot | ✅ готово |

Каждая папка содержит полный комплект артефактов сдачи и собственный отчёт; входной точкой в каждом ДЗ служит `ОТЧЕТ.md` / файлы по формату сдачи задания.

## Итоги сквозного проекта (ДЗ1 → ДЗ6)

Один проект прошёл полный жизненный цикл:

1. **ДЗ1** — сравнение 6 AI-инструментов, выбор Claude Code под требования проекта;
2. **ДЗ2** — правила работы агента (CLAUDE.md, 14 правил) и промпт-шаблоны RTCF;
3. **ДЗ3** — проектирование: 3 UI-концепции, 19 пользовательских историй, ТЗ (70 FR + 18 NFR);
4. **ДЗ4** — frontend по ТЗ (React + Vite + Tailwind, Mock-режим, покрытие тестами);
5. **ДЗ5** — backend Supabase: Postgres + RLS, Auth, авто-RestAPI, фасад Mock↔облако, e2e;
6. **ДЗ6** — эксплуатация: CI/CD-конвейер, деплой Vercel, OAuth2 Google, аналитика,
   health-check, мониторинг, аудит безопасности.

Приложение живое: push в `main` автоматически проходит линт, 170 тестов и сборку,
выкатывается на Vercel; здоровье зависимостей контролируют `/api/health`
и внешний мониторинг UptimeRobot, продуктовые метрики собирает Яндекс.Метрика.
